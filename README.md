# Food Delivery Visualization Portfolio — Day 14

This repository contains the completed Day 14 visualization assignment.

## Files
- `Day14_Food_Delivery_Visualization_Portfolio.ipynb` — complete Jupyter/Google Colab notebook
- `Day14_Food_Delivery_Visualization_Dataset.csv` — dataset used by the notebook

## How to run
1. Upload both files to Google Colab, or clone/download the repository.
2. Open the `.ipynb` notebook.
3. Run all cells from top to bottom.

The notebook uses:
- pandas
- numpy
- matplotlib
- seaborn

## Main analysis areas
Orders and revenue trends, city performance, cuisine performance, marketing spend vs revenue, delivery time vs customer rating, delivery-time distribution, weather effects, order channels, and correlation analysis.
